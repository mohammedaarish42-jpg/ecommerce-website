# ShopEase – E-commerce Website

A responsive product listing website with product details, search, filtering and a shopping cart.

**Technologies:** HTML, CSS, JavaScript, React.js

## Files
- `index.html` – the page (HTML), loads React
- `style.css` – the look and the mobile layout (CSS)
- `products.js` – the product list (JavaScript)
- `app.jsx` – the app: product grid, details popup, search, filters, cart (React.js)

## How to run it
1. Right-click an empty space inside the `ecommerce-website` folder and choose **Open in Terminal**.
2. Type:
   ```
   python -m http.server 8000
   ```
3. Open **http://127.0.0.1:8000** in your browser.

Press `Ctrl + C` in the terminal to stop it. An internet connection is needed (React loads from the web).
